🎨 Visualização das Camadas PCB

📍 Camada Superior — Componentes e Soldagem

Componentes Visíveis:

  • Q1-Q6: MOSFETs 600V/100A (IPP65R600P7)
  • U1: Gate Driver DRV8302
  • C1-C2: Capacitores bulk 470µF
  • C3: Filme 100µF (filtro PWM)
  • R1-R3: Shunts 0.001Ω (sensores corrente)
  • L1-L3: Ferrites 1µH (filtro EMI)
  • J1-J3: Conectores fases motor (XT60)
  • J4: Conector DC input (Anderson)
📊 Informações Adicionais

Características de Design:

  • ✅ Vias termais: ~200 vias sob MOSFETs para dissipação
  • ✅ Plano GND: Continuo em layer 2 (baixa impedância)
  • ✅ Plano VCC: Continuo em layer 3 (distribuição potência)
  • ✅ Silk screen: Designadores de componentes
  • ✅ Trilhas 50A: Largura otimizada para correntes altas
  • ✅ Separação: Sinal/Potência isolados (EMI)
  • ✅ Soldadura: Pads HASL (compatível manual + reflow)

Materiais:

  • FR-4 1.6mm (padrão industrial)
  • Cobre 2oz/lado (70µm)
  • Soldermask verde (proteção)
  • Silkscreen branco
