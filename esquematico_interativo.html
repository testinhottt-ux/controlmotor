⚙️ Fluxo de Energia e Sinais

Fluxo de Controle (Microcontrolador → Motor)

ESP32 (Firmware SimpleFOC)
  │
  ├─→ Calcula algoritmo FOC (10kHz)
  │   └─ Park-Clarke Transform
  │   └─ PI Controllers (Id, Iq)
  │   └─ Inverse Park Transform
  │
  ├─→ Gera PWM (20kHz, 3-phase)
  │   └─ GPIO pins → PWM_U, PWM_V, PWM_W
  │
  └─→ DRV8302 (Gate Driver)
      │
      ├─→ 15V Gate Signals
      │   ├─ GATE_HS_U/V/W (High-side)
      │   └─ GATE_LS_U/V/W (Low-side)
      │
      └─→ MOSFET Bridge
          │
          ├─→ Commutation → Phase voltages
          │   ├─ Phase_U: +0 to +400V ou 0 a -200V
          │   ├─ Phase_V: +0 to +400V ou 0 a -200V
          │   └─ Phase_W: +0 to +400V ou 0 a -200V
          │
          └─→ Motor 3-fases
              │
              ├─ Rotating magnetic field
              ├─ Torque = Kt × Iq
              └─ Speed = ω = Voltage/Ψ

Fluxo de Sensoriamento (Motor → Microcontrolador)

Motor Sensors (Back-EMF + Hall)
  │
  ├─→ Hall Sensors (Phase U, V, W)
  │   └─ Commutation feedback (6-step detection)
  │
  ├─→ Current Shunts (R1, R3, R5)
  │   │
  │   ├─ Fase_U: I_u = V(phase_u_sense) / 0.001Ω
  │   ├─ Fase_V: I_v = V(phase_v_sense) / 0.001Ω
  │   └─ Fase_W: I_w = V(phase_w_sense) / 0.001Ω
  │
  │   └─→ ADC (ESP32)
  │       └─ 3 channels × 16-bit
  │       └─ 1V = 100A (sensitivity)
  │
  └─→ Control Loop Feedback
      └─ Measure Id, Iq
      └─ Adjust PWM duty
      └─ Maintain torque reference

🔗 Guia de Conexões

Entrada de Potência

  • Anderson +400V → VDC
  • Anderson GND → GND
  • Capacitor: VDC ⟷ GND (2×470µF)
  • Fusível: 100A entre VDC e capacitor

Gate Driver (DRV8302)

  • PWM_U,V,W ← ESP32 GPIO (0-5V)
  • VDD (15V) ← Regulador interno
  • GND ← Referência comum
  • GATE_HS/LS → Q1-Q6 gate pads

Sensores

  • Hall_U,V,W ← Motor (logística separada)
  • I_sense_U,V,W ← Phase_X output → ADC
  • Temp NTC ← Thermistor near MOSFETs
  • Voltage divider: 400V → 3.3V ADC range

Saídas do Motor

  • Phase_U ← Inversor → XT60 conector U
  • Phase_V ← Inversor → XT60 conector V
  • Phase_W ← Inversor → XT60 conector W
  • GND ← Inversor → GND motor (comum)

⚠️ Parâmetros Críticos de Design

Timings e Limitações

OPERAÇÃO NORMAL:
├─ VDC: 350-420V (nominal 400V)
├─ Corrente: 0-100A (nominal 50A)
├─ PWM Freq: 20 kHz (exatamente)
├─ Dead-time: ≥ 200ns (shoot-through prevention)
├─ Motor Freq: 0-600 Hz (0-18000 RPM equiv.)
└─ Temp junção: 0-125°C (máx 150°C)

PROTEÇÕES ATIVAS:
├─ OVP (Over Voltage Protection): > 420V → desativa
├─ OCP (Over Current Protection): > 100A → desativa
├─ Thermal: > 85°C → reduz duty cycle
├─ Under Voltage Lockout (UVLO): < 350V → desativa
└─ Fault flag → ESP32 interrupt

RIPPLE MÁXIMO TOLERADO:
├─ DC-link: ±20V (5%)
├─ Corrente fase: ±15A (30%)
└─ Temperatura dissipador: ±10°C
